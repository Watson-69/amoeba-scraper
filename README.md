## 🌟 Project Overview

**amoeba-scraper** is a **production-ready REST API** that programmatically extracts game metadata from **[FitGirl Repacks](https://fitgirl-repacks.site)** — one of the most trusted sources for compressed game repacks. The API scrapes, normalizes, and stores game information into a MySQL database, exposing it through clean, well-documented endpoints.

> 💡 **Use cases:** Building a game launcher, personal collection tracker, research tool analyzing repack trends, or any application needing structured game metadata.

---

## ✨ Key Capabilities

| Capability | Description |
|------------|-------------|
| **Automated Scraping** | Scheduled or on-demand with pagination, search queries, and detail enrichment |
| **Rich Metadata** | Titles, sizes, magnet links, info hashes, genres, years, posters, descriptions |
| **Flexible Search** | Full-text search, category filtering, seeder thresholds, multi-field sort orders |
| **Cron-Ready Sync** | Secure background sync for Vercel Cron, GitHub Actions, or any scheduler |
| **Rate-Limit Friendly** | Configurable delays, exponential backoff, Cloudflare challenge detection |
| **Idempotent Operations** | Re-running scrapes upserts data; zero duplicates guaranteed |
| **Type-Safe** | Strict TypeScript, zero `any`, full type coverage |
| **Observability** | Structured logging, scrape run history, baseline tracking |

## 🚀 Quick Start

### Prerequisites

- **Node.js** ≥ 20
- **MySQL** ≥ 8.0 (or MariaDB ≥ 10.5)
- **npm** or **pnpm**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Watson-69/amoeba-scraper.git
cd amoeba-scraper

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env.local
# Edit .env.local with your MySQL credentials

# 4. Initialize the database schema
npm run db:init

# 5. (Optional) Populate with initial data
npm run scrape                    # Recent releases
npm run scrape -- --query="hades" --pages=5 --items=50  # Targeted search
npm run scrape -- --full          # Full archive (slow)

# 6. Start development server
npm run dev
```

> 🎉 Server runs at **http://localhost:3000** — open it to see the built-in API documentation page!

| Variable | Required | Default | Description |
|----------|:--------:|---------|-------------|
| `MYSQL_HOST` | ✅ | `localhost` | MySQL host |
| `MYSQL_PORT` | ✅ | `3306` | MySQL port |
| `MYSQL_USER` | ✅ | `root` | MySQL username |
| `MYSQL_PASSWORD` | ✅ | — | MySQL password |
| `MYSQL_DATABASE` | ✅ | `amoeba_scraper` | Database name |
| `CRON_SECRET` | ❌ | — | Bearer token for `/api/cron/sync` |
| `SCRAPER_DELAY_MS` | ❌ | `900` | Delay between requests (ms) |
| `SCRAPER_TIMEOUT_MS` | ❌ | `20000` | Request timeout (ms) |
| `NODE_ENV` | ❌ | `development` | Environment mode |

### Scraper Behavior

- **Delay between requests**: Configured via `SCRAPER_DELAY_MS` (default 900ms)
- **Request timeout**: Configured via `SCRAPER_TIMEOUT_MS` (default 20s)
- **Retry logic**: Exponential backoff (2s, 4s, 8s) with max 3 retries
- **Challenge detection**: Automatically detects Cloudflare challenges and 429 responses

### 🔄 Scraping Operations

| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| `POST` | `/api/scrape` | Trigger a scrape (targeted or full archive) | — |
| `GET` | `/api/scrape` | Get last scrape run status | — |

#### POST `/api/scrape` — Trigger Scrape

**Request Body:**
```json
{
  "query": "string (optional)",
  "maxPages": "number (optional, default: 3)",
  "maxItems": "number (optional, default: 50)",
  "fetchDetails": "boolean (optional, default: true)",
  "fullArchive": "boolean (optional, default: false)"
}
```

**Examples:**

```bash
# Targeted scrape
curl -X POST http://localhost:3000/api/scrape \
  -H "Content-Type: application/json" \
  -d '{
    "query": "hades",
    "maxPages": 3,
    "maxItems": 50,
    "fetchDetails": true,
    "delayMs": 900
  }'

# Full archive scrape
curl -X POST http://localhost:3000/api/scrape \
  -H "Content-Type: application/json" \
  -d '{"fullArchive": true}'
```

**Response:**
```json
{
  "ok": true,
  "found": 25,
  "inserted": 20,
  "updated": 5,
  "warnings": []
}
```

#### GET `/api/scrape` — Scrape Status

```bash
curl http://localhost:3000/api/scrape
```

**Response:**
```json
{
  "ok": true,
```

## 📦 Data Model

### Torrent Object

```typescript
interface Torrent {
  id: string;                    // Unique ID: "amoeba:base64url"
  title: string;                 // Game title
  size_bytes: number | null;     // File size in bytes
  seeders: number;               // Current seeders
  leechers: number;              // Current leechers
  uploaded_at: string | null;    // Upload timestamp (YYYY-MM-DD HH:MM:SS)
  category: string | null;       // Category (e.g., "games")
  source_site: string;           // Source identifier ("amoeba")
  source_url: string | null;     // Original source URL
  magnet_link: string | null;    // Magnet link
  info_hash: string | null;      // Torrent info hash (40-char hex)
  description: string | null;    // Full description
  poster_url: string | null;     // Poster/cover image URL
  genres: string[] | null;       // Genre tags
  year: number | null;           // Release year
  rating: number | null;         // Rating (0-10)
  details: string | null;        // Short description snippet
  last_scraped_at: string;       // Last update timestamp
}
```

### Scrape Request

```typescript
interface ScrapeRequest {
  query?: string;          // Search query (optional)
  maxPages?: number;       // Max pages to scrape (default: 3)
  maxItems?: number;       // Max items to collect (default: 50)
  fetchDetails?: boolean;  // Enrich with detail pages (default: true)
  fullArchive?: boolean;   // Full archive mode (default: false)
}
```

### Scrape Response

```typescript
interface ScrapeResponse {
  ok: boolean;
  found: number;           // Total items found
  inserted: number;        // New items inserted
  updated: number;         // Existing items updated
  warnings: string[];      // Non-fatal warnings
}
```

## 🗄 Database Schema

Two tables created by `npm run db:init`:

```sql
-- Scraped game torrent metadata
CREATE TABLE torrents (
  id              VARCHAR(64) PRIMARY KEY,
  title           VARCHAR(500) NOT NULL,
  size_bytes      BIGINT UNSIGNED NULL,
  seeders         INT UNSIGNED DEFAULT 0,
  leechers        INT UNSIGNED DEFAULT 0,
  uploaded_at     DATETIME NULL,
  category        VARCHAR(64) NULL,
  source_site     VARCHAR(128) NOT NULL,
  source_url      TEXT NULL,
  magnet_link     TEXT NULL,
  info_hash       CHAR(40) NULL,
  description     MEDIUMTEXT NULL,
  poster_url      TEXT NULL,
  genres_json     JSON NULL,
  year            SMALLINT UNSIGNED NULL,
  rating          DECIMAL(3,1) NULL,
  details         TEXT NULL,
  last_scraped_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FULLTEXT KEY `ft_title` (`title`, `description`),
  KEY `idx_category` (`category`),
  KEY `idx_uploaded` (`uploaded_at`),
  KEY `idx_seeders` (`seeders`),
  KEY `idx_source_site` (`source_site`),
  KEY `idx_info_hash` (`info_hash`),
  KEY `idx_year` (`year`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Scrape run history for monitoring
CREATE TABLE scrape_logs (
  id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  source_site     VARCHAR(128) NOT NULL,
  status          ENUM('success','partial','failed') NOT NULL,
  items_found     INT UNSIGNED DEFAULT 0,
  items_inserted  INT UNSIGNED DEFAULT 0,
  items_updated   INT UNSIGNED DEFAULT 0,
  error_message   TEXT NULL,
  started_at      DATETIME NOT NULL,
  completed_at    DATETIME NULL,
  KEY `idx_source_started` (`source_site`, `started_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 🛠 Troubleshooting

### 🔴 Database Connection Failed

```
Error: connect ECONNREFUSED 127.0.0.1:3306
```

**Solutions:**
- Verify MySQL is running: `systemctl status mysql` or `mysqladmin ping`
- Check credentials in `.env.local` match your MySQL user/password
- Ensure the database exists: `npm run db:init`
- Check firewall/security groups allow port 3306

### 🟡 Scrape Returns 0 Results / Site Blocked

```
Warning: FitGirl blocked or challenged (status 403)
```

**Solutions:**
- Increase `SCRAPER_DELAY_MS` in `.env.local` (e.g., `2000`)
- The target site may be rate-limiting — wait and retry
- Check if Cloudflare challenge page is returned (scraper detects this)
- Try again later or use a VPN/proxy
- Verify `SCRAPER_USER_AGENT` is set to a valid browser string

### 🔵 TypeScript / Module Errors

```
Error: Cannot find module '@/lib/db'
```

**Solutions:**
- Run `npm install` to ensure all dependencies are installed
- Run `npm run build` to check for TypeScript errors
- Ensure Node.js version is ≥ 20: `node --version`
- Check `tsconfig.json` path aliases match your structure

### 🟠 Cron Endpoint Returns 401

```
Response: Unauthorized
```

**Solutions:**
- Set `CRON_SECRET` in `.env.local`
- Include header: `Authorization: Bearer your-cron-secret`
- Ensure no extra whitespace in the token

## ❓ FAQ

**Q: Does this download game files?**
A: No. This only scrapes **publicly available metadata** (titles, sizes, magnet links, etc.) from FitGirl Repacks. No game files are downloaded or hosted.

**Q: Can I add other sources besides FitGirl?**
A: Yes! The scraper architecture is extensible. Add a new file in `src/lib/scrapers/` implementing the same interface, then register it in `scrape-service.ts`.

**Q: How often should I run the cron sync?**
A: Every 15-30 minutes is reasonable for catching new releases. Adjust based on your needs and rate limits.

**Q: What does "idempotent" mean here?**
A: Running the same scrape multiple times will not create duplicates. Existing records are updated in place based on the unique `id` field.

**Q: Can I use this in production?**
A: Yes, with proper configuration: set `NODE_ENV=production`, use a managed MySQL instance, configure `CRON_SECRET`, and set appropriate rate limits.

**Q: Why are some fields null in the API response?**
A: Not all games have complete metadata on the source site. Fields like `info_hash`, `poster_url`, or `rating` may be unavailable for older entries.
